Ever wanted to see what screaming into your microphone looks like on this website's visualizer? No?
Well, too bad, I added it anyway. This update's [revamped visualizer playground](/misc/visualizer)
now gives you the option to visualize audio coming from a microphone (or your system, if supported).

Not only that, the [version list](/version#version-list) has received a redesign, and versions can
now also have a size associated with them. This version, for instance, should be a **regular
update**. For now, every update that already had release notes _(`0.4.0-rc.1` and later)_ has been
assigned one of these sizes.

And to top it off, primary buttons have been given a new look as well. Here's one, for example:

button!</button>

it remains to be seen.
