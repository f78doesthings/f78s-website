Ever wanted to see what screaming into your microphone looks like on this website's visualizer? No?
Well, I added it anyway. This update's [revamped visualizer playground](/misc/visualizer) now lets
you visualize audio coming from a microphone (or your system, if supported).

Not only that, versions can now also have a size associated with them; this version, for instance,
should be a **regular update**. For now, all versions that already had release notes (`0.4.0-rc.1`
and later) have been given a size. You can see them in the version list, which has also been
redesigned.

And to top it off, primary buttons have been given a new look. Here's one, for example:
