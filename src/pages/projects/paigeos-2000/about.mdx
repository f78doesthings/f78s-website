_"What if Paige was in Windows 2000?"_

Introducing **PaigeOS 2000**, a small modification for Windows 2000 themed around everyone's
favourite little indie platformer,
[Home Paige](https://store.steampowered.com/app/4098960/Home_Paige/).

You're currently experiencing an **interactive simulation** of PaigeOS 2000 in your web browser. You
should definitely try to, you know, interact with things. Like you would on Windows. _It's not 100%
accurate, but that's not important. Also, your experience will probably be better in a
Chromium-based browser for now (sorry)._

Want to subject your Windows 2000 installation to Paige? Then head over to the project's
[GitLab repository](https://gitlab.com/f78doesthings/PaigeOS-2000)! It's fully open source under the
**GPL-3.0** (or later) licence. But before you go and install it, I encourage you to read the
repository's **README** first; it contains some important information to help you get started.

## Why?

I intended for this to be a silly little gag for one of my music videos at first. But then I saw
some [Home Paige Discord](https://discord.gg/homepaige) members wanted to install it on real
hardware, so I decided to spend a few days making an installer and releasing this project to the
public. _You're welcome! <small>Even though it's making me procrastinate on my other
projects...</small>_

If you want to know why I picked Windows 2000, that's because its bootscreen says "Starting up...",
which I named
[a song](https://soundcloud.com/f78music/starting-up?in=f78music/sets/home-paige-covers) after.
Also, Windows 2000 was released in 1999, which makes it a 90s operating system. And that's what Home
Paige is set-- _wait, what do you mean they removed that line from the store page?_ ... Oh, I see.
They're going for a Windows XP vibe. And that came out in 2001. Alright then.

In that case, I suppose Windows XP would've been a better fit for a modification like this. Except
then, my "Starting up..." reference wouldn't make sense any more. And I also just don't feel
comfortable making resources that fit Windows XP better, because I'm not an artist. This is about
the best I can do.
